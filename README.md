# Family Tree Management & Visualization

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Deployed on Cloudflare Pages](https://img.shields.io/badge/Cloudflare_Pages-deployed-F38020?logo=cloudflare&logoColor=white)](https://pages.cloudflare.com)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

Interactive family tree management and visualization platform built with React and Vite. It focuses on intuitive family lineage management and exploration, with optional GEDCOM support for interoperability with external genealogy tools.

## Core Capabilities

### 1. Universal Format Compatibility & Live Code Editor
Industry-standard GEDCOM 5.5.1 specification compliance with an integrated Monaco editor buffer, two-way synchronized graph validation, and syntax checks.

<p align="center">
  <img src="https://sanak-asset.muhaemen.my.id/editor.gif" alt="Universal Format Compatibility & Live Code Editor" width="100%" />
</p>

### 2. Interactive Visual Canvas & Kinship Path Finder
Intuitive generational canvas layout with pan/zoom controls, one-click relative connections, and multi-branch graph traversal resolving relationship paths and vantage-point addressing.

<p align="center">
  <img src="https://sanak-asset.muhaemen.my.id/node.gif" alt="Interactive Visual Canvas & Kinship Path Finder" width="100%" />
</p>

### 3. Private Local Storage & Google Drive Sharing
Client-side sandbox storage in browser IndexedDB with zero telemetry, paired with Google Drive cloud sync for cross-device access and sharing.

<p align="center">
  <img src="https://sanak-asset.muhaemen.my.id/load.gif" alt="Private Local Storage & Google Drive Sharing" width="100%" />
</p>

### 4. Rich Profiles & Direct Family Contact
Extended record fields for burial grounds, residential addresses, contact details, Google Maps navigation coordinates, and WhatsApp communication shortcuts.

<p align="center">
  <img src="https://sanak-asset.muhaemen.my.id/contact_address.gif" alt="Rich Profiles & Direct Family Contact" width="100%" />
</p>

### 5. Regional & Customary Kinship Titles *(In Development)*
Localized kinship dictionary automatically resolving traditional address terms across Indonesian traditions (Banjar, Dayak, Javanese, Sundanese, Minang, and Batak).

## Future Features

- **Expanded Regional Kinship Dictionaries**: Further expansion of localized address forms and dialect variants across Nusantara traditions ([#7](https://github.com/miftahulmuhaemen/family-tree/issues/7)).
